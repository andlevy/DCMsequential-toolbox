## Time-Varying DCM

seq-DCM extends conventional DCM by modelling smooth temporal evolution of synaptic and neural parameters, thereby capturing plasticity and non-stationary dynamics in neural and physiological systems. Unlike standard DCM, which assumes time-invariant parameters, seq-DCM represents a generative modelling framework that allows parameters to transition smoothly between discrete physiological states using sigmoid-weighted interpolation.

### DCM for sequential responses

Parameter trajectories

The present seq-DCM framework substantially extends parameter expressiveness by enabling temporal trajectories for all model parameters, including:

1. **Baseline & Modulatory Synaptic Efficacies** (A&B matrices) - capturing both evolving baseline connectivity "set points" and experimentally-driven connection modulation
2. **Intrinsic Synaptic efficacies** (G) -  synaptic connections within a neural mass model
3. **Neural mass parameters** (T, H,D) - population-level gain, time constants, axonal and synaptic transmission delays

The sigmoid width σ determines the temporal scale of synaptic change:

* **σ ~ 10-50 ms**: Fast plasticity (e.g., short-term depression/facilitation)
* **σ ~ 100-500 ms**: Intermediate dynamics (e.g., attention shifts, state transitions)
* **σ ~ 1-5 s**: Slow adaptation (e.g., learning, habituation)

### Biological Plausibility

The sigmoid functional form approximates several biological processes:

1. **Hebbian plasticity**: Gradual strengthening/weakening of synapses
2. **Neuromodulation**: Slow accumulation/clearance of modulatory substances
3. **Network reconfiguration**: Distributed synaptic changes across populations

When **extrinsic synaptic efficacies (A & B matrices)** evolve over hundreds of milliseconds to seconds, they most obviously capture **neuromodulatory dynamics** - particularly dopaminergic, cholinergic, and noradrenergic fluctuations that dynamically reconfigure effective connectivity between brain regions in response to task demands and attentional states. **Intrinsic synaptic efficacies (G)** at these timescales primarily reflect **metabotropic receptor dynamics**, especially NMDA and GABA\_B receptor kinetics that modulate local excitation-inhibition balance within cortical columns through slower G-protein coupled signalling cascades. Evolving **time constants (T)** most directly map to **changes in membrane conductances** via voltage-gated channel modulation (particularly calcium-activated potassium currents) that alter neuronal integration windows. **Population gains (H)** on this timescale predominantly capture **spike-frequency adaptation mechanisms** - the activity-dependent reduction in neuronal excitability mediated by adaptation currents such as the M-current and afterhyperpolarization that shape population-level input-output relationships. Finally, slowly varying **delays (D)** most plausibly reflect **synaptic transmission delay fluctuations** arising from calcium-dependent changes in vesicle release probability and dendritic computation time, rather than changes in axonal conduction velocity which operate on much longer timescales.

### Transition points
Beyond differences in parameter scope, seq-DCM and the Medrano DCT approach differ fundamentally in how they conceptualise and model the temporal structure of neurophysiological data. These architectural differences have important implications for experimental design, model flexibility, and biological interpretation.

seq-DCM framework models data as a single continuous timeseries with smoothly evolving parameters. An "epoch" is treated as one unified observation generated by a dynamical system whose parameters transition continuously between discrete physiological states that coincide with experimental manipulations. The generative model integrates the neural state equations forward in time, with parameters θ(t) evaluated at every integration timestep via the trajectory function. This produces a single, coherent prediction of the observed timeseries. <!-- what does this afford -->. 
In contrast, the Medrano method models data as a collection of paritioned epochs or time bins, each treated as a separate "condition" in the DCM framework. The timeseries is segmented into K consecutive windows, and while the same model structure is used across windows, each epoch is effectively modelled independently with its own effective connectivity values Ec​(tk​). Temporal continuity is imposed through the design matrix structure (basis functions evaluated at epoch midpoints), but the fundamental unit of analysis is the epoch rather than the continuous timeseries.

#### Mixtures of transition types
This architectural difference enables seq-DCM to naturally accommodate mixtures of transition types that would be challenging to represent in epoch-based frameworks. Both approaches can model transitions driven by experimental manipulations. In seq-DCM, transition times τi​ can be fixed to stimulus onset times. In the Medrano approach, epochs are typically aligned to stimulus presentation, with the DCT basis set capturing modulation across the trial sequence. seq-DCM can additionally model transitions that occur independently of experimental inputs, reflecting intrinsic brain state changes such as:

* Attention fluctuations during sustained tasks
* Arousal state transitions during long recordings
* Spontaneous network reorganisation during resting state
* Physiological cycles (cardiac, respiratory) that are measured but not experimentally controlled

These endogenous transitions are naturally incorporated by estimating transition times {τ1​,…,τK​} as free parameters, or by fixing them to measured physiological markers (ECG R-peaks, respiration peaks) that were recorded concurrently but not experimentally manipulated. The continuous modelling framework allows these endogenous transitions to occur at arbitrary timepoints, not constrained to epoch boundaries.

Crucially, seq-DCM enables modeling of paradigms where some transitions are stimulus-locked (exogenous) whilst others reflect ongoing physiological or cognitive processes (endogenous). For example, in a cardiac-gated attention task:

* Cardiac phase transitions (τcardiac​): endogenous, fixed to measured R-peaks
* Task epoch transitions (τtask​): exogenous, fixed to stimulus onsets
* Attention state transitions (τattention​): endogenous, potentially estimated from data or inferred from behavioral markers

This flexibility is essential for naturalistic experiments where brain dynamics reflect the superposition of multiple timescales and driving forces.


#### Irregular transition intervals
Fourier and discrete cosine bases are mathematically optimised for regularly sampled data and periodic phenomena. While the Medrano implementation uses a Lomb-Scargle-like approach (evaluating basis functions at arbitrary timepoints tk​) to partially mitigate this, the spectral interpretation of DCT coefficients assumes relatively uniform temporal sampling. Highly irregular transition spacing can lead to:
* **Spectral leakage**: Energy from irregular temporal structure spreads across multiple basis functions, reducing interpretability
* **Increased basis order requirements**: Capturing irregular timing patterns may require higher-order basis sets, increasing parameter count
* **Aliasing**: If some transition intervals are very short and others very long, the Nyquist criterion becomes ambiguous
In practice, DCT-based approaches work best for experimental designs with relatively regular temporal structure (e.g., fixed ISI, regular block designs), whereas seq-DCM is more naturally suited to irregular, physiologically-driven, or naturalistic timing.


The continuous modelling approach naturally accommodates irregularly spaced transitions. Because transition times {τ1​,…,τK​} are specified individually (either fixed from experimental design or estimated), there is no constraint that they be evenly distributed. This is particularly advantageous for:

* **Event-related designs with variable ISI**: Experiments using jittered inter-stimulus intervals, exponentially distributed sequence lengths (as in roving oddball), or naturalistic stimulus timing.

* **Multi-scale dynamics**: Paradigms where rapid transitions (e.g., stimulus-evoked responses, ~100-300 ms) are interspersed with slower transitions (e.g., block design task switches, ~10-60 s).

* **Cardiac-gated experiments**: Inter-beat intervals vary naturally with heart rate variability (typically 600-1200 ms). seq-DCM directly incorporates the actual R-peak times from each cardiac cycle without requiring interpolation or temporal warping.
 **Physiologically-driven transitions**: Any paradigm where transitions are locked to measured biological signals (respiration, pupil dilation, muscle activity) which inherently have irregular timing.

Both approaches represent important advances in modeling non-stationary neural dynamics, with complementary strengths. The choice between them should be guided by experimental design, the nature of the transitions under study (exogenous vs endogenous), and the temporal structure of the paradigm (regular vs irregular). For cardiac-gated neurophysiology and other paradigms with irregular, physiologically-determined transitions, seq-DCM's continuous modeling framework offers substantial advantages in flexibility, interpretability, and computational efficiency.

### Complexity
The trade-off is computational: while both approaches face parameter expansion, seq-DCM's cost scales with the number of states (K+1) across all evolving parameters, whereas DCT-based methods scale with the number of basis functions ($N_b$) per connection. However, seq-DCM offers greater interpretability, as discrete states correspond to explicit physiological epochs rather than abstract frequency components

## Trajectory Function Definition

Let $\theta(t)$ denote a time-varying parameter vector (e.g., connectivity matrix, gain parameter). In seq-DCM, $\theta(t)$ is modelled as a weighted sum of discrete parameter states:
$$\theta(t) = \theta_1 + \sum_{i=1}^{N} [\theta_{i+1} - \theta_i] \cdot v_i(t)$$where:
- $N$ = number of transitions
- $\theta_i$ = parameter value in state _i_ (estimated from data)
- $v_i(t)$ = sigmoid transition function for transition _i_

Each sigmoid function $v_i(t)$ smoothly transitions from 0 to 1, effectively 'blending' consecutive parameter states without discontinuities. <!-- explain it in terms of a piecewise operation -->.The transition functions are implemented as cumulative Gaussian error functions:
$$v_i(t) = 0.5 \cdot [1 + \text{erf}((t - \tau_i) / (\sqrt{2} \cdot \sigma_i))]$$where:
- $\tau\_i$ = temporal centre of transition \*i\* (milliseconds)
- $\sigma\_i$ = temporal width (standard deviation) of transition \*i\*
- $\text{erf}()$ = Gaussian error function

The transition width is parameterised in log-space to enable estimation:
$$\sigma_i = \frac{d_i}{2.563103} \cdot \exp(K_i)$$
where:
- $d\_i$ = nominal transition duration (milliseconds, typically set to inter-transition interval)
- $K\_i$ = log-scale parameter (estimated from data via variational Bayes)
- 2.563103 = normalisation constant (approximately $2\sigma$ encompasses 98% of sigmoid transition)


This formulation ensures:

1. **Smooth transitions**: $C^\infty$ continuity (infinitely differentiable)
2. **Bounded range**: $v\_i(t) \in \[0, 1]$
3. **Physiological interpretability**: $\tau\_i$ controls \*when\* transitions occur; $\sigma\_i$ controls \*how fast\*
4. locked to known event structure


### Log-Space Parameterisation for Positive Parameters
For parameters constrained to be positive (e.g., synaptic gains, time constants, connection strengths), the trajectory operates in log-space:
$\theta(t) = \exp\left[\log(\theta_1) + \sum_{i=1}^{K} [\log(\theta_{i+1}) - \log(\theta_i)] \cdot v_i(t)\right]$
This ensures $\theta(t) > 0$ for all $t$ whilst allowing unconstrained optimisation in log-space, improving numerical stability and biological realism.

## Model Inversion
We  implemented the sequential DCM as a formal extension of the generic DCM framework introduced by van Wijk and colleagues (van Wijk et al., 2018). This approach was motivated by the recognition that sequential responses often engage multiple interacting physiological systems, each with distinct intrinsic dynamics and timescales. Rather than constraining our implementation to a single neural mass model, the generic framework allows us to couple heterogeneous models representing different brain regions, physiological systems, or levels of biological detail within a unified architecture.

The generic framework removed this restriction by establishing a standardized interface for coupling arbitrary neural mass models through extrinsic connections. This allows, for example, cortical regions to be modeled using laminar microcircuit models whilst subcortical structures employ models tailored to their specific anatomical organization. Critically, the framework maintains mathematical consistency across these heterogeneous models by ensuring that extrinsic coupling operates through well-defined afferent and efferent connections between specified hidden states.

For sequential DCM, this flexibility is essential. Time-varying connectivity must be expressed across neural populations with fundamentally different intrinsic properties—from fast-spiking cortical interneurons to slower autonomic control circuits. By building on the generic framework, our implementation can accommodate parameter trajectories for any neural mass model currently available in SPM, whilst also facilitating the incorporation of future models without requiring substantial architectural changes. Moreover, the generic framework has been extensively validated in previous applications, providing a robust foundation upon which to build the sequential extensions.


The key innovation distinguishing sequential DCM from standard generic DCM is the incorporation of parameter trajectories. In conventional DCM, parameters such as connection strengths are assumed constant throughout the observation period, whereas in sequential DCM these parameters become functions of time, evolving smoothly according to the sigmoid-based trajectory model described previously. The implementation detects when parameters are specified as time-varying and evaluates the appropriate trajectory function at each integration time point, computing current parameter values by interpolating between discrete parameter states. This approach applies uniformly across all parameter types—extrinsic connection matrices, intrinsic coupling strengths, and time constants—and maintains consistency with the underlying variational Laplace scheme by ensuring that all trajectory functions and their derivatives can be computed analytically. The computation of network dynamics proceeds by first evaluating intrinsic flows for each neural mass model through calls to model-specific functions, then adding extrinsic contributions by summing weighted influences from connected nodes, with each connection contributing proportionally to source population activity and current connection strength. This separation of intrinsic and extrinsic dynamics maintains modularity whilst accommodating time-varying connectivity. Time delays are incorporated through a Taylor series approximation that absorbs the delay operator into the system Jacobian, ensuring numerical stability whilst capturing phase relationships introduced by conduction delays, with different neural mass models assigned characteristic intrinsic delays reflecting typical conduction times within their anatomical substrates.

## Supporting Implementation Features

Beyond the core trajectory integration, several complementary features have been introduced to accommodate the specific requirements of sequential DCM and to enhance computational efficiency. First, the parameter trajectory functions themselves are incorporated within the input structure (U) rather than being treated separately. This design choice reflects the recognition that parameter evolution represents an endogenous process—a form of internal drive that shapes network dynamics independently of external experimental stimulation. Importantly, this arrangement facilitates compatibility with certain inversion schemes in SPM that evaluate the Jacobian with respect to inputs. By treating trajectories as a form of input, we ensure that these schemes correctly account for parameter dynamics even in experimental paradigms lacking explicit external stimulation, where traditional input-driven variability would otherwise be absent.

Second, we have extended the repertoire of driving functions available for modeling exogenous inputs to neural populations. The standard SPM implementation provides `spm_erp_u`, which generates brief, high-amplitude bump functions appropriate for modeling transient sensory-evoked responses. For sequential paradigms involving sustained dynamics, we have introduced `spm_scp_u` (slow cortical potential), which implements asymmetric, low-amplitude, long-duration driving functions. These functions are designed to capture the sustained thalamocortical drive characteristic of slow cortical potentials and other prolonged physiological processes. The asymmetry of these functions—with gradual onset and more rapid offset—reflects the typical temporal profile of endogenous neural state changes and provides a more appropriate prior for modeling extended timescale dynamics than the symmetric functions used for evoked responses.

Third, to address the computational demands of sequential DCM—which typically involves longer time series, more parameters, and more complex trajectory evaluations than conventional DCM—we have implemented optimizations for numerical differentiation and prior specification. The function `spm_diff_par` provides a parallelized implementation of the numerical differentiation routines used to compute Jacobians during model inversion. This parallelization exploits multi-core processors to distribute the computation of partial derivatives across available cores, yielding substantial speed improvements proportional to processor core count. Additionally, we have developed `spm_dcm_priorcorr`, a utility function for specifying prior correlations between parameters. By allowing researchers to encode known dependencies or constraints between parameters—for instance, that certain connection strengths are expected to covary—this function reduces the effective dimensionality of the parameter space. This reduction in model complexity not only improves computational efficiency but can also enhance parameter identifiability by incorporating domain knowledge into the prior distribution, thereby regularizing the inverse problem in a principled manner consistent with the Bayesian framework.
