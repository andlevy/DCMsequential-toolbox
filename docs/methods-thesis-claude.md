# Methods: Sequential Dynamic Causal Modelling with Trajectory-Based Parameter Evolution

## Overview

Sequential Dynamic Causal Modelling (seq-DCM) extends conventional DCM by modelling smooth temporal evolution of synaptic and neural parameters, thereby capturing plasticity and non-stationary dynamics in neural and physiological systems. Unlike standard DCM, which assumes time-invariant parameters, seq-DCM represents a generative modelling framework that allows parameters to transition smoothly between discrete physiological states using sigmoid-weighted interpolation.

## Relationship to Existing Time-Varying DCM Approaches

Recent developments in time-varying DCM have introduced temporal dynamics into connectivity parameters using basis function expansions. Notably, Medrano et al. (2024) proposed a framework using discrete cosine transform (DCT) basis sets to model time-varying modulatory connectivity (B parameters), while maintaining fixed intrinsic connectivity (A parameters). This approach demonstrated improved model fit for non-stationary neural data, but restricted temporal variation to experimentally modulated connections.

The present seq-DCM framework substantially extends parameter expressiveness by enabling temporal trajectories for **all** model parameters, including:

1. **Intrinsic connectivity** (A matrices): capturing evolving baseline connectivity 'set points'
2. **Modulatory connectivity** (B matrices): experimentally driven connection modulation
3. **Neural mass parameters** (G, T, H): population-level gain, time constants, and synaptic efficacies
4. **Conduction delays** (D): axonal and synaptic transmission delays

This increased expressiveness enables modelling of fundamental state transitions (e.g., cardiac cycle phases, arousal states) that modify the intrinsic organisation of neural circuits, not merely their modulation by experimental inputs. The trade-off is computational: whilst both approaches face parameter expansion, seq-DCM's cost scales with the number of states ($K+1$) across all evolving parameters, whereas DCT-based methods scale with the number of basis functions ($N_b$) per connection. However, seq-DCM offers greater interpretability, as discrete states correspond to explicit physiological epochs rather than abstract frequency components.

## Continuous vs Epoch-Based Modeling: Fundamental Architectural Differences

Beyond differences in parameter scope, seq-DCM and the Medrano DCT approach differ fundamentally in how they conceptualise and model the temporal structure of neurophysiological data. These architectural differences have important implications for experimental design, model flexibility, and biological interpretation.

### Continuous Data Modeling

**seq-DCM**: The sequential DCM framework models data as a single **continuous timeseries** with smoothly evolving parameters. The entire experimental recording—from the first to the last timepoint—is treated as one unified observation generated by a dynamical system whose parameters transition continuously between discrete physiological states. The generative model integrates the neural state equations forward in time, with parameters $\theta(t)$ evaluated at every integration timestep via the trajectory function. This produces a single, coherent prediction of the observed timeseries.

**Medrano DCT approach**: In contrast, the Medrano method models data as a collection of **discrete epochs** or time bins, each treated as a separate "condition" in the DCM framework. The timeseries is segmented into $K$ consecutive windows, and while the same model structure is used across windows, each epoch is effectively modelled independently with its own effective connectivity values $E_c(t_k)$. Temporal continuity is imposed through the design matrix structure (basis functions evaluated at epoch midpoints), but the fundamental unit of analysis is the epoch rather than the continuous timeseries.

### Implications for Transition Types and Sources

This architectural difference enables seq-DCM to naturally accommodate **mixtures of transition types** that would be challenging to represent in epoch-based frameworks:

**1. Exogenous (stimulus-driven) transitions**: Both approaches can model transitions driven by experimental manipulations. In seq-DCM, transition times $\tau_i$ can be fixed to stimulus onset times (e.g., R-peaks in cardiac-gated experiments, tone onsets in oddball paradigms). In the Medrano approach, epochs are typically aligned to stimulus presentation, with the DCT basis set capturing modulation across the trial sequence.

**2. Endogenous (spontaneous) transitions**: seq-DCM can additionally model transitions that occur independently of experimental inputs, reflecting intrinsic brain state changes such as:
   - Attention fluctuations during sustained tasks
   - Arousal state transitions during long recordings
   - Spontaneous network reorganisation during resting state
   - Physiological cycles (cardiac, respiratory) that are measured but not experimentally controlled

These endogenous transitions are naturally incorporated by estimating transition times $\{\tau_1, \ldots, \tau_K\}$ as free parameters, or by fixing them to measured physiological markers (ECG R-peaks, respiration peaks) that were recorded concurrently but not experimentally manipulated. The continuous modeling framework allows these endogenous transitions to occur at arbitrary timepoints, not constrained to epoch boundaries.

**3. Mixed exogenous-endogenous designs**: Crucially, seq-DCM enables modeling of paradigms where some transitions are stimulus-locked (exogenous) whilst others reflect ongoing physiological or cognitive processes (endogenous). For example, in a cardiac-gated attention task:
   - Cardiac phase transitions ($\tau_\text{cardiac}$): endogenous, fixed to measured R-peaks
   - Task epoch transitions ($\tau_\text{task}$): exogenous, fixed to stimulus onsets
   - Attention state transitions ($\tau_\text{attention}$): endogenous, potentially estimated from data or inferred from behavioral markers

This flexibility is essential for naturalistic experiments where brain dynamics reflect the superposition of multiple timescales and driving forces.

### Irregular Temporal Spacing

**seq-DCM flexibility**: The continuous modeling approach naturally accommodates **irregularly spaced transitions**. Because transition times $\{\tau_1, \ldots, \tau_K\}$ are specified individually (either fixed from experimental design or estimated), there is no constraint that they be evenly distributed. This is particularly advantageous for:

- **Cardiac-gated experiments**: Inter-beat intervals vary naturally with heart rate variability (typically 600-1200 ms). seq-DCM directly incorporates the actual R-peak times from each cardiac cycle without requiring interpolation or temporal warping.

- **Event-related designs with variable ISI**: Experiments using jittered inter-stimulus intervals, exponentially distributed sequence lengths (as in roving oddball), or naturalistic stimulus timing.

- **Multi-scale dynamics**: Paradigms where rapid transitions (e.g., stimulus-evoked responses, ~100-300 ms) are interspersed with slower transitions (e.g., block design task switches, ~10-60 s).

- **Physiologically-driven transitions**: Any paradigm where transitions are locked to measured biological signals (respiration, pupil dilation, muscle activity) which inherently have irregular timing.

**DCT basis set limitations**: Fourier and discrete cosine bases are mathematically optimised for **regularly sampled data** and periodic phenomena. While the Medrano implementation uses a Lomb-Scargle-like approach (evaluating basis functions at arbitrary timepoints $t_k$) to partially mitigate this, the spectral interpretation of DCT coefficients assumes relatively uniform temporal sampling. Highly irregular transition spacing can lead to:

- **Spectral leakage**: Energy from irregular temporal structure spreads across multiple basis functions, reducing interpretability
- **Increased basis order requirements**: Capturing irregular timing patterns may require higher-order basis sets, increasing parameter count
- **Aliasing**: If some transition intervals are very short and others very long, the Nyquist criterion becomes ambiguous

In practice, DCT-based approaches work best for experimental designs with relatively regular temporal structure (e.g., fixed ISI, regular block designs), whereas seq-DCM is more naturally suited to irregular, physiologically-driven, or naturalistic timing.

### Computational and Conceptual Implications

**Forward model integration**:

- **seq-DCM**: Integrates state equations once across the entire timeseries, evaluating $\theta(t)$ at each integration timestep. Computational cost: $O(T \cdot K)$ where $T$ is total integration time and $K$ is number of transitions (typically $K \ll T$).

- **Medrano**: If implemented with continuous integration within each epoch, the cost is similar: $O(T \cdot N_b)$ where $N_b$ is number of basis functions. However, the conceptual framing as separate epochs may encourage windowed analysis approaches which could be less efficient.

**Temporal smoothness constraints**:

- **seq-DCM**: Smoothness is enforced directly through the sigmoid transition functions $v_i(t)$, which are $C^\infty$ continuous. The transition width $\sigma_i$ provides explicit control over temporal smoothness at each transition.

- **Medrano**: Smoothness emerges implicitly from the spectral properties of the DCT basis set—higher frequencies are typically down-weighted by priors, encouraging smooth trajectories. However, smoothness is a global property of the basis set, not adjustable per-transition.

**Interpretability**:

- **seq-DCM**: Discrete states $\{\theta_1, \ldots, \theta_{K+1}\}$ have direct physiological interpretation (e.g., "systolic connectivity", "diastolic connectivity"). Posterior estimates directly answer questions like "How does connectivity differ between cardiac phases?"

- **Medrano**: DCT coefficients represent frequency components of the connectivity trajectory. Interpretation requires projecting coefficients onto the time domain (i.e., reconstructing $E_c(t)$ via Equation 3 in Medrano et al.). Coefficients themselves are less directly interpretable.

**Model comparison and selection**:

- **seq-DCM**: Different hypotheses about the number of states ($K$) or which parameters have trajectories can be compared directly via free energy. Questions like "Is there a discrete systolic-diastolic transition?" vs "Is cardiac modulation continuous?" correspond to different $K$ values.

- **Medrano**: Model comparison focuses on basis set order ($N_b$). Questions about discrete vs continuous changes are less directly addressable, as the DCT framework assumes smooth, continuous modulation by construction.

### Summary of Architectural Differences

| Feature | seq-DCM | Medrano DCT |
|---------|---------|-------------|
| **Data structure** | Continuous timeseries | Epoched conditions |
| **Transition types** | Mixed exogenous/endogenous | Primarily exogenous |
| **Temporal spacing** | Arbitrary, irregular | Best for regular spacing |
| **Parameter interpretation** | Discrete physiological states | Spectral frequency components |
| **Smoothness control** | Per-transition ($\sigma_i$) | Global (basis set order) |
| **Flexibility** | All parameters can vary | Typically B matrices only |
| **Best suited for** | Physiologically-driven, irregular designs | Experimentally-controlled, regular designs |

Both approaches represent important advances in modeling non-stationary neural dynamics, with complementary strengths. The choice between them should be guided by experimental design, the nature of the transitions under study (exogenous vs endogenous), and the temporal structure of the paradigm (regular vs irregular). For cardiac-gated neurophysiology and other paradigms with irregular, physiologically-determined transitions, seq-DCM's continuous modeling framework offers substantial advantages in flexibility, interpretability, and computational efficiency.

## Mathematical Formulation

### Trajectory Function Definition

Let $\theta(t)$ denote a time-varying parameter vector (e.g., connectivity matrix, gain parameter). In seq-DCM, $\theta(t)$ is modelled as a weighted sum of discrete parameter states:

$$
\theta(t) = \theta_1 + \sum_{i=1}^{K} [\theta_{i+1} - \theta_i] \cdot v_i(t)
$$

where:
- $K$ = number of transitions
- $\theta_i$ = parameter value in state *i* (estimated from data)
- $v_i(t)$ = sigmoid transition function for transition *i*
- $t$ = time (milliseconds)

Each sigmoid function $v_i(t)$ smoothly transitions from 0 to 1, effectively 'blending' consecutive parameter states without discontinuities.

### Sigmoid Transition Functions

The transition functions are implemented as cumulative Gaussian error functions:

$$
v_i(t) = 0.5 \cdot [1 + \text{erf}((t - \tau_i) / (\sqrt{2} \cdot \sigma_i))]
$$

where:
- $\tau_i$ = temporal centre of transition *i* (milliseconds)
- $\sigma_i$ = temporal width (standard deviation) of transition *i*
- $\text{erf}()$ = Gaussian error function

This formulation ensures:
1. **Smooth transitions**: $C^\infty$ continuity (infinitely differentiable)
2. **Bounded range**: $v_i(t) \in [0, 1]$
3. **Physiological interpretability**: $\tau_i$ controls *when* transitions occur; $\sigma_i$ controls *how fast*

The transition width is parameterised in log-space to enable estimation:

$$
\sigma_i = \frac{d_i}{2.563103} \cdot \exp(K_i)
$$

where:
- $d_i$ = nominal transition duration (milliseconds, typically set to inter-transition interval)
- $K_i$ = log-scale parameter (estimated from data via variational Bayes)
- 2.563103 = normalisation constant (approximately $2\sigma$ encompasses 98% of sigmoid transition)

### Log-Space Parameterisation for Positive Parameters

For parameters constrained to be positive (e.g., synaptic gains, time constants, connection strengths), the trajectory operates in log-space:

$$
\theta(t) = \exp\left[\log(\theta_1) + \sum_{i=1}^{K} [\log(\theta_{i+1}) - \log(\theta_i)] \cdot v_i(t)\right]
$$

This ensures $\theta(t) > 0$ for all $t$ whilst allowing unconstrained optimisation in log-space, improving numerical stability and biological realism.

### Trajectory of Covariance

In addition to modelling time-varying mean parameters, seq-DCM can incorporate temporal evolution of parameter covariance (uncertainty). Following the framework of Medrano et al. (2024), the posterior covariance of parameters can itself vary across time, reflecting changes in parameter identifiability or physiological variability across different epochs.

Let $\Sigma(t)$ denote the time-varying posterior covariance matrix. This can be parameterised using the same trajectory framework:

$$
\Sigma(t) = \Sigma_1 + \sum_{i=1}^{K} [\Sigma_{i+1} - \Sigma_i] \cdot v_i(t)
$$

where $\Sigma_i$ is the posterior covariance in state *i*. To ensure positive-definiteness, the covariance matrices can be parameterised via their Cholesky decompositions:

$$
\Sigma_i = L_i L_i^T
$$

where $L_i$ is a lower-triangular matrix. The trajectory then operates on the Cholesky factors:

$$
L(t) = L_1 + \sum_{i=1}^{K} [L_{i+1} - L_i] \cdot v_i(t)
$$

with $\Sigma(t) = L(t) L(t)^T$. This formulation:

1. **Preserves positive-definiteness**: $\Sigma(t)$ remains a valid covariance matrix for all $t$
2. **Captures uncertainty dynamics**: Reflects changing parameter identifiability across physiological states
3. **Enables state-dependent inference**: Posterior confidence varies with physiological context

In cardiac applications, this allows modelling of differential parameter certainty across cardiac phases. For instance, if baroreceptor input is strongest during systole, connectivity parameters may be more precisely estimated in systolic epochs, corresponding to smaller $\Sigma_i$ during those periods.

**Computational considerations**: Including time-varying covariance increases parameter count by $\frac{n(n+1)}{2} \times (K+1)$ for $n$ parameters with trajectories. This is typically reserved for models where state-dependent uncertainty is theoretically motivated (e.g., phase-dependent sensory precision) rather than applied routinely.

## Implementation

### Forward Model Integration

During numerical integration of the neural state equations, parameters are updated at each time step by evaluating:

```matlab
θ_t = spm_dcm_trajectory({θ_1, θ_2, ..., θ_{K+1}}, v(t), logscale)
```

where $v(t) = [v_1(t), v_2(t), \ldots, v_K(t)]$ is the vector of sigmoid values at time $t$. This function performs a single-pass weighted accumulation:

1. Initialise with first state: $\theta(t) = \theta_1$
2. For each transition $k = 1:K$:
   - Add weighted difference: $\theta(t) \leftarrow \theta(t) + (\theta_{k+1} - \theta_k) \times v_k(t)$
3. Return $\theta(t)$

Computational complexity is $O(K)$ per evaluation, where $K$ is the number of transitions (typically 1 to 4 for cardiac or task-based paradigms).

### Parameter Estimation

The model parameters are organised hierarchically:

1. **Structural parameters** (estimated): Discrete states $\{\theta_1, \ldots, \theta_{K+1}\}$ for each evolving parameter
   - Prior: Multivariate Gaussian $\mathcal{N}(\mu_\theta, \Sigma_\theta)$
   - Estimated via variational Laplace using gradient ascent on free energy

2. **Temporal parameters**:
   - Transition times $\{\tau_1, \ldots, \tau_K\}$: Fixed based on experimental design (e.g., cardiac R-peaks) or estimated
   - Transition widths $\{K_1, \ldots, K_K\}$: Estimated with weakly informative priors $\mathcal{N}(0, 1)$

The total number of free parameters is:

$$
N_{\text{params}} = \sum_{p=1}^{P} (K_p + 1) \cdot \dim(\theta_p) + N_{\text{widths}}
$$

where $P$ is the number of parameter types with trajectories, $K_p$ is the number of transitions for parameter type $p$, $\dim(\theta_p)$ is the dimensionality of that parameter, and $N_\text{widths}$ is the number of estimated transition widths (if not fixed).

### Comparison with DCT Basis Set Approaches

The DCT-based approach (Medrano et al., 2024) parameterises time-varying connectivity as:

$$
B_j(t) = \sum_{b=1}^{N_b} w_{jb} \cdot \phi_b(t)
$$

where $B_j(t)$ is the modulatory effect on connection $j$, $\phi_b(t)$ are DCT basis functions, and $w_{jb}$ are weights. For $N_\text{conn}$ connections, this requires $N_\text{conn} \times N_b$ parameters.

**Parameter count comparison** (example: 4-node network, 2 transitions):

| Approach | Time-varying parameters | Free parameters |
|----------|------------------------|-----------------|
| DCT (Medrano) | B only ($N_\text{conn}$ = 16) | $16 \times 8 = 128$ (with $N_b = 8$ basis functions) |
| seq-DCM (minimal) | B only | $16 \times 3 = 48$ (with $K = 2$ states) |
| seq-DCM (full) | A, B, G, T, H | $(16+16+4+4+4) \times 3 = 132$ |

**Key distinction**: seq-DCM with full parameter evolution (including intrinsic connectivity A) achieves comparable parameter counts to DCT-based B-only models, but with substantially greater expressiveness. The cost per forward evaluation is similar ($O(K)$ vs $O(N_b)$), but seq-DCM parameters directly correspond to physiological states rather than frequency components.

## Applications to Cardiac-Gated Neurophysiology

In cardiac-gated experiments, neural activity is temporally aligned to cardiac phases (e.g., systole vs diastole). seq-DCM is particularly suited to this paradigm:

1. **Transition specification**: $\tau_i$ set to cardiac R-peak times (fixed from ECG)
2. **State interpretation**: $\theta_1$ = systolic connectivity, $\theta_2$ = diastolic connectivity
3. **Physiological priors**: Informed by known cardiac-neural coupling mechanisms

This approach captures:
- **Intrinsic connectivity changes** (A trajectories): baroreceptor-mediated baseline shifts
- **Modulatory changes** (B trajectories): task-dependent modulation varying across cardiac phases
- **Neural excitability changes** (G, H trajectories): cardiac-phase-dependent gain modulation

### Temporal Resolution

The sigmoid width $\sigma_i$ determines the temporal scale of parameter evolution:

- **$\sigma \sim 10$ to 50 ms**: fast synaptic plasticity (short-term depression/facilitation)
- **$\sigma \sim 100$ to 500 ms**: intermediate state transitions (cardiac phases, attention shifts)
- **$\sigma \sim 1$ to 5 s**: slow adaptation (learning, arousal state changes)

For cardiac applications, $\sigma \sim 100$ to 300 ms is typical, capturing the gradual transition between systolic and diastolic states.

## Model Comparison and Selection

Different model architectures (varying $K$, parameter selection for trajectories) are compared using variational free energy $F$, which approximates log model evidence:

$$
F = \log p(y|m) \approx \langle \log p(y|\theta, m) \rangle_{q(\theta)} - D_\text{KL}(q(\theta) \| p(\theta|m))
$$

where $y$ is observed data, $m$ is the model, $\theta$ are parameters, and $q(\theta)$ is the approximate posterior. Higher $F$ indicates better balance between fit and complexity.

**Model selection strategy**:
1. Start with $K$ determined by experimental design (e.g., number of cardiac phases)
2. Test alternative trajectory specifications (e.g., A-only, A+B, full parameters)
3. Compare using Bayes factors: $\text{BF} = \exp(\Delta F)$ for nested models
4. Prefer parsimony: only include trajectories if $\Delta F > 3$ (strong evidence)

## Advantages and Limitations

**Advantages**:
1. **Biological interpretability**: discrete states correspond to physiological epochs
2. **Parameter efficiency**: estimate $K+1$ states rather than continuous functions
3. **Flexibility**: applicable to any DCM parameter type
4. **Regularisation**: Gaussian priors on discrete states prevent overfitting
5. **Gradient-based optimisation**: smooth trajectories enable efficient variational inference

**Limitations**:
1. **Computational cost**: scales with number of states and evolving parameters
2. **Prior sensitivity**: requires informative priors for high-dimensional state spaces
3. **Identifiability**: multiple transitions may be poorly identified with limited data
4. **Monotonicity assumption**: current formulation assumes unidirectional state transitions

## Software Implementation

seq-DCM is implemented in MATLAB as an extension of the SPM12 DCM framework. Core functions include:

- `spm_dcm_trajectory.m`: Trajectory interpolation at time t
- `spm_seq_u.m`: Sigmoid function generation and input specification
- `spm_fx_seq.m`: Sequential neural dynamics with time-varying parameters
- `spm_nlsi_N_par.m`: Variational inversion with parallelization
- `spm_dcm_synaptic_trajectory.m`: Post-hoc reconstruction of full trajectories

The toolbox supports parallel processing for multi-subject/multi-condition inference and includes diagnostics for convergence assessment and posterior predictive checks.

## Conclusion

Sequential DCM with trajectory-based parameter evolution provides a principled, flexible framework for modelling non-stationary neural dynamics. By extending time-varying parameterisation beyond experimentally modulated connections to include intrinsic connectivity and neural mass parameters, seq-DCM captures richer physiological state transitions whilst maintaining computational tractability and interpretability. This framework is particularly well suited to cardiac-gated neurophysiology, where discrete physiological states (cardiac phases) induce systematic changes in neural circuit organisation.
