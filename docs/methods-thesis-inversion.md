# Implementation within SPM: Extension of Generic DCM

## Motivation for a Generalized Framework

The modeling of sequential responses—where neural dynamics evolve continuously over extended timescales—presents unique computational challenges that require a flexible and extensible implementation framework. We have addressed this by implementing sequential DCM as a formal extension of the generic DCM framework introduced by van Wijk and colleagues (van Wijk et al., 2018). This approach was motivated by the recognition that sequential responses often engage multiple interacting physiological systems, each with distinct intrinsic dynamics and timescales. Rather than constraining our implementation to a single neural mass model, the generic framework allows us to couple heterogeneous models—representing different brain regions, physiological systems, or levels of biological detail—within a unified architecture.

Prior to the introduction of generic DCM, computational models within SPM were typically restricted to homogeneous networks where the same neural mass model was applied uniformly across all nodes. While this constraint simplified implementation, it limited the biological realism of models spanning multiple brain systems. The generic framework removed this restriction by establishing a standardized interface for coupling arbitrary neural mass models through extrinsic connections. This allows, for example, cortical regions to be modeled using laminar microcircuit models whilst subcortical structures employ models tailored to their specific anatomical organization. Critically, the framework maintains mathematical consistency across these heterogeneous models by ensuring that extrinsic coupling operates through well-defined afferent and efferent connections between specified hidden states.

For sequential DCM, this flexibility is essential. Time-varying connectivity must be expressed across neural populations with fundamentally different intrinsic properties—from fast-spiking cortical interneurons to slower autonomic control circuits. By building on the generic framework, our implementation can accommodate parameter trajectories for any neural mass model currently available in SPM, whilst also facilitating the incorporation of future models without requiring substantial architectural changes. Moreover, the generic framework has been extensively validated in previous applications, providing a robust foundation upon which to build the sequential extensions.

## Implementation Architecture

The core computational implementation is contained within the function `spm_fx_seq.m`, which serves as the central routine for computing the flow and Jacobian for networks of coupled neural mass models with time-varying parameters. The implementation builds directly on the generic DCM framework (van Wijk et al., 2018), which enables different neural mass models to be coupled within a single network by establishing a standardized interface for extrinsic connections. Each neural mass model defines a set of hidden states, and the generic framework requires explicit specification of which states serve as sources (efferent connections) and targets (afferent connections) for inter-model communication through index arrays. Connection-specific scaling factors are assigned to reflect the characteristic coupling strengths and temporal dynamics of different connection types, expressed in physiological units. At present, our implementation supports six distinct neural mass models—ERP, CMC, BGT, MMC, HMC, and CVP—each encoding domain-specific knowledge about its target system whilst being seamlessly coupleable within the sequential framework. The interested reader is referred to van Wijk et al. (2018) for a comprehensive treatment of the generic DCM architecture and its advantages over earlier homogeneous implementations.

## Integration of Time-Varying Parameters

The key innovation distinguishing sequential DCM from standard generic DCM is the incorporation of parameter trajectories. In conventional DCM, parameters such as connection strengths are assumed constant throughout the observation period, whereas in sequential DCM these parameters become functions of time, evolving smoothly according to the sigmoid-based trajectory model described previously. The implementation detects when parameters are specified as time-varying and evaluates the appropriate trajectory function at each integration time point, computing current parameter values by interpolating between discrete parameter states. This approach applies uniformly across all parameter types—extrinsic connection matrices, intrinsic coupling strengths, and time constants—and maintains consistency with the underlying variational Laplace scheme by ensuring that all trajectory functions and their derivatives can be computed analytically. The computation of network dynamics proceeds by first evaluating intrinsic flows for each neural mass model through calls to model-specific functions, then adding extrinsic contributions by summing weighted influences from connected nodes, with each connection contributing proportionally to source population activity and current connection strength. This separation of intrinsic and extrinsic dynamics maintains modularity whilst accommodating time-varying connectivity. Time delays are incorporated through a Taylor series approximation that absorbs the delay operator into the system Jacobian, ensuring numerical stability whilst capturing phase relationships introduced by conduction delays, with different neural mass models assigned characteristic intrinsic delays reflecting typical conduction times within their anatomical substrates.

## Supporting Implementation Features

Beyond the core trajectory integration, several complementary features have been introduced to accommodate the specific requirements of sequential DCM and to enhance computational efficiency. First, the parameter trajectory functions themselves are incorporated within the input structure (U) rather than being treated separately. This design choice reflects the recognition that parameter evolution represents an endogenous process—a form of internal drive that shapes network dynamics independently of external experimental stimulation. Importantly, this arrangement facilitates compatibility with certain inversion schemes in SPM that evaluate the Jacobian with respect to inputs. By treating trajectories as a form of input, we ensure that these schemes correctly account for parameter dynamics even in experimental paradigms lacking explicit external stimulation, where traditional input-driven variability would otherwise be absent.

Second, we have extended the repertoire of driving functions available for modeling exogenous inputs to neural populations. The standard SPM implementation provides `spm_erp_u`, which generates brief, high-amplitude bump functions appropriate for modeling transient sensory-evoked responses. For sequential paradigms involving sustained dynamics, we have introduced `spm_scp_u` (slow cortical potential), which implements asymmetric, low-amplitude, long-duration driving functions. These functions are designed to capture the sustained thalamocortical drive characteristic of slow cortical potentials and other prolonged physiological processes. The asymmetry of these functions—with gradual onset and more rapid offset—reflects the typical temporal profile of endogenous neural state changes and provides a more appropriate prior for modeling extended timescale dynamics than the symmetric functions used for evoked responses.

Third, to address the computational demands of sequential DCM—which typically involves longer time series, more parameters, and more complex trajectory evaluations than conventional DCM—we have implemented optimizations for numerical differentiation and prior specification. The function `spm_diff_par` provides a parallelized implementation of the numerical differentiation routines used to compute Jacobians during model inversion. This parallelization exploits multi-core processors to distribute the computation of partial derivatives across available cores, yielding substantial speed improvements proportional to processor core count. Additionally, we have developed `spm_dcm_priorcorr`, a utility function for specifying prior correlations between parameters. By allowing researchers to encode known dependencies or constraints between parameters—for instance, that certain connection strengths are expected to covary—this function reduces the effective dimensionality of the parameter space. This reduction in model complexity not only improves computational efficiency but can also enhance parameter identifiability by incorporating domain knowledge into the prior distribution, thereby regularizing the inverse problem in a principled manner consistent with the Bayesian framework.

## Advantages and Future Extensions

This implementation strategy provides several important advantages. First, it ensures modularity—new neural mass models can be incorporated by defining their dynamics, specifying their connection architecture, and integrating them into the dispatch mechanism within `spm_fx_seq.m`. Second, it maintains full compatibility with the existing SPM ecosystem, leveraging established numerical integration routines, visualization tools, and model comparison frameworks. Third, it provides computational efficiency through sparse matrix operations, vectorization, and adaptive schemes for delay approximation. Finally, and perhaps most importantly, it provides scientific flexibility—allowing researchers to construct biologically realistic models spanning multiple brain systems and physiological scales, all whilst accommodating smooth parameter evolution over time.

Looking forward, the generic framework positions sequential DCM to readily incorporate future developments in neural mass modeling. As more sophisticated models of specific brain systems are developed—for instance, detailed models of hippocampal circuits or cerebellar dynamics—these can be integrated into the sequential framework with minimal modification to the core architecture. This extensibility is crucial for a technique intended to address increasingly complex questions about neural plasticity and the dynamics of distributed brain systems.
